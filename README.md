# candidate-crm
A PostgreSQL-based candidate CRM that uses SQL, AI, and workflow automation to prioritize job opportunities, tailor application materials, and analyze application performance.

# Career Intelligence Platform

A personal project built to strengthen my SQL, relational database design, and full-stack development skills while solving a real-world problem.

## Goal

Build an application that helps manage the job search process by tracking:

- Companies
- Jobs
- Applications
- Professional Contacts

The long-term vision includes:

- Resume management
- AI resume matching
- Cover letter generation
- Networking tracking
- Job analytics
- Application dashboards

## Technologies

- PostgreSQL
- Supabase
- Git
- GitHub
